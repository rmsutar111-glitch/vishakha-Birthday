# Vishakha Birthday Surprise — Professional Edition 💗

Made for Vishakha, from Rushikesh. Includes all 9 uploaded photos, responsive gallery, gift reveal, birthday letter, wish interaction, confetti, and a tap-to-play spoken birthday message using the browser’s built-in speech synthesis. The song section and YouTube link have been removed. The voice requires a browser that supports speech synthesis and may use the voices installed on the visitor’s device.

## Preview locally
1. Extract this ZIP.
2. Open the extracted folder in Visual Studio Code.
3. Right-click `index.html` and select **Open with Live Server**.


## Publish free with GitHub Pages
1. Create a public repository at https://github.com named `vishakha-birthday`.
2. Upload `index.html`, `style.css`, `script.js`, and the entire `photos` folder to the repository root.
3. Commit changes.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for deployment and open the URL GitHub Pages shows.

## Photos
The gallery includes all nine uploaded images under `photos/memory1.jpg` through `photos/memory9.jpg`. You can change the crop using `object-position` rules in `style.css`.
